# PIXA — AI 圖片工作室

一個零依賴的 AI 圖片生成與編輯工具前端原型。介面包含圖片生成、圖片編輯、提示詞優化、風格切換、尺寸設定、圖片張數控制、進階創意強度、成果預覽與下載互動。

## 啟動方式

```bash
python3 -m http.server 4173
```

啟動後前往 <http://localhost:4173>。

## 功能

- 圖片生成與圖片編輯模式切換
- 圖片上傳與檔案大小檢查
- 提示詞字數統計、清除和 AI 優化模擬
- 風格選擇、圖片比例、生成張數和創意強度設定
- 模擬圖片生成 Loading 狀態
- 成果圖切換版型、重新生成與下載提示
- 響應式桌面、平板與手機版面
